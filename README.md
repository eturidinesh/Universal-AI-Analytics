# 🚀 Universal AI Analytics

AI-powered analytics platform built using Streamlit.

## Features

- 📊 Dynamic Dashboard
- 🔮 Forecasting using Machine Learning
- 🧠 AI Insights
- 💬 Chat with Data
- 📄 PDF and CSV Reports
- 🗺 Geographic Analysis
- 📈 KPI Metrics
- 🔥 Correlation Heatmap
- ⚠ Anomaly Detection

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn
- ReportLab
